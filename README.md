# Business Management System (BMS)

Aplikasi web untuk membantu mengelola bisnis jual-beli berbagai jenis barang elektronik. BMS menyediakan pencatatan produk, persediaan, pembelian, penjualan, keuangan, dan laporan bisnis.

## Fitur Utama

- Dashboard ringkasan bisnis.
- Manajemen produk dan persediaan.
- Pencatatan serial number, kondisi, dan status barang.
- Pencatatan pembelian dan penjualan.
- Pengelolaan keuangan, pengeluaran, prive, dan penambahan modal.
- Laporan laba rugi, arus kas, dan persediaan.

## Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **ORM:** Prisma
- **Validation:** Zod
- **API:** REST
